# Prometheus Architecture Diagram (text)

Shows: how Prometheus scrapes exporters, how it talks to Alertmanager,
and how Grafana pulls data from Prometheus.

Flow summary:

1. **Prometheus → Exporters (pull):** service discovery feeds the target list; Prometheus
   issues `GET /metrics` to every target every `scrape_interval` and stores samples in
   its TSDB.
2. **Prometheus → Alertmanager (push of alert events):** alerting rules that fire are
   POSTed to Alertmanager, which groups/silences/inhibits and notifies receivers.
3. **Grafana → Prometheus (pull of query results):** Grafana holds a Prometheus
   data source and sends PromQL instant/range queries over HTTP for its panels.
