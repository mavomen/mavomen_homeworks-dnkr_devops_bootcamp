# 3. download a file (two ways)

## classic client:
$ cd /tmp && ftp -invp ftp.gnu.org -> user anonymous anonymous -> get MISSING-FILES.README
-rw-r--r-- 1 mava mava 4178 Aug 21 19:54 /tmp/MISSING-FILES.README

## same with wget:
$ wget -q --timeout=20 ftp://ftp.gnu.org/MISSING-FILES.README

# 4. upload attempt on public server
anonymous ftp servers are read-only, upload gets refused:
$ curl -T testfile ftp://ftp.gnu.org/incoming/
curl: (9) Server denied you to change to the given directory

upload only works on your own server (proved in setup_ftp.sh docker test):
$ curl -T local.txt --user ftpuser:ftpuser123 ftp://SERVER/files/
